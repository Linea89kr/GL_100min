# 100분 해커톤 웹게임 템플릿

이 레포는 **Use this template**로 복사해서, `index.html` 단일 파일 웹게임을 만들어 GitHub Pages로 제출하기 위한 템플릿입니다.

## 해커톤 주제 (택 1)
1. 개발 공부·성장·학습을 돕는 도구
2. 소통·친목·연결을 돕는 도구
3. 스터디 운영·반복 업무를 줄이는 도구

## 규칙
- 결과물은 **단일 `index.html` 파일 1개**로 제출합니다.
- 서버(백엔드) 사용 금지, 브라우저에서 바로 실행 가능해야 합니다.
- 외부 라이브러리는 **CDN `<script>` 태그** 방식만 허용합니다.
- 그래픽은 이미지 대신 **이모지 + 색 블록** 중심으로 구성합니다.

## 타임라인 (총 100분)
- 0–5분: 킥오프
- 5–15분: 아이디어 확정
- 15–65분: 제작
- 65–80분: 버그 수정·데모 준비 (새 기능 금지)
- 80–95분: 발표
- 95–100분: 마무리

## 제출 방법
- 제출물: GitHub Pages 주소 1개
- Settings → Pages로 이동
- Build and deployment에서 Source를 `Deploy from a branch`로 설정
- Branch를 `main` / `/root`로 설정 후 Save
